## 📝 Project Submission Guidelines

### Submission location & naming
- Add your notebook to this course folder (or an optional subfolder).
- Use descriptive filenames (e.g. `groupname_project.ipynb`) and avoid spaces.
- Ensure the first markdown cell contains `Author:` or `Group:` with your group name (the site reads this value).

### File Naming
- Use descriptive names for your notebooks
- Examples:
  - `exploratory_data_analysis.ipynb`
  - `covid_data_analysis.ipynb`
  - `stock_market_analysis.ipynb`

### Project Content

Your Jupyter notebook should include:

1. **Title Cell** (Markdown)
   - Project title
   - Your name
   - Date
   - Brief description

2. **Introduction**
   - Project objective
   - Problem statement
   - Dataset description and source

3. **Data Loading & Exploration**
   - Import necessary libraries
   - Load dataset
   - Display basic information (shape, columns, data types)
   - Summary statistics

4. **Data Cleaning**
   - Identify and handle missing values
   - Remove duplicates
   - Handle outliers
   - Data type corrections

5. **Analysis & Visualization**
   - Exploratory data analysis (EDA)
   - Create meaningful visualizations
   - Statistical insights
   - Patterns and trends

6. **Findings & Conclusion**
   - Key insights
   - Answer research questions
   - Limitations
   - Future improvements

### Required Libraries (Examples)
Students typically use:
- `pandas` - Data manipulation and analysis
- `numpy` - Numerical computing
- `matplotlib` - Basic plotting
- `seaborn` - Statistical visualization
- `plotly` - Interactive visualizations (optional)

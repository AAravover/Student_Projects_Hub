📂 Folder Structure

Place your notebook file directly in this course folder (you may create an optional subfolder). The site automatically extracts the group/author name from the notebook's first markdown cell.

Data_Analysis_using_Python/ ├── README.md (this file) ├── group_alpha_project1.ipynb ├── group_beta_analysis.ipynb └── optional_subfolder/ └── another_project.ipynb

📝 Project Submission Guidelines

Submission location & naming

  • Add your notebook to this course folder (or an optional subfolder).
  • Use descriptive filenames (e.g. groupname_project.ipynb) and avoid spaces.
  • Ensure the first markdown cell contains Author: or Group: with your group name (the site reads this value).

File Naming

  • Use descriptive names for your notebooks
  • Examples:
  • exploratory_data_analysis.ipynb
  • covid_data_analysis.ipynb
  • stock_market_analysis.ipynb

Project Content

Your Jupyter notebook should include:

  1. Title Cell (Markdown)
  2. Project title
  3. Your name
  4. Date

  5. Brief description

  6. Introduction

  7. Project objective
  8. Problem statement

  9. Dataset description and source

  10. Data Loading & Exploration

  11. Import necessary libraries
  12. Load dataset
  13. Display basic information (shape, columns, data types)

  14. Summary statistics

  15. Data Cleaning

  16. Identify and handle missing values
  17. Remove duplicates
  18. Handle outliers

  19. Data type corrections

  20. Analysis & Visualization

  21. Exploratory data analysis (EDA)
  22. Create meaningful visualizations
  23. Statistical insights

  24. Patterns and trends

  25. Findings & Conclusion

  26. Key insights
  27. Answer research questions
  28. Limitations
  29. Future improvements

Required Libraries (Examples)

Students typically use: - pandas - Data manipulation and analysis - numpy - Numerical computing - matplotlib - Basic plotting - seaborn - Statistical visualization - plotly - Interactive visualizations (optional)

✅ Checklist Before Submission

  • [ ] All cells execute successfully (Kernel → Restart & Run All)
  • [ ] Code includes comments explaining logic
  • [ ] Markdown cells provide context and explanations
  • [ ] All plots have appropriate titles, labels, and legends
  • [ ] Results are interpreted and explained
  • [ ] No sensitive or proprietary data included
  • [ ] File is placed in this course folder (not in other students' files)
  • [ ] No large files (> 10MB) included

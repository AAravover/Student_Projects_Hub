# Contributing to Student Projects Hub

Thank you for your interest in contributing to the Student Projects Hub! This guide will help you submit your projects successfully.

## 🎯 Who Can Contribute?

This repository is primarily for students enrolled in the following courses:
- Python for Data Analytics II
- Data Analysis using Python
- Future courses (to be announced)

## 📤 Submission Process

Please follow the detailed instructions in the main [README.md](README.md) file.

### Quick Summary

1. **Fork** the repository
2. **Navigate** to your course folder (`[year]/[course_name]/`)
3. **Create** your personal folder (`your_name/`)
4. **Upload** your Jupyter notebook(s)
5. **Commit** your changes
6. **Create** a pull request

## ✅ Submission Checklist

Before submitting your pull request, ensure:

- [ ] Your project is in the correct year and course folder
- [ ] You have created a personal folder with your name
- [ ] Your notebook file has a descriptive name
- [ ] All code cells run without errors
- [ ] Your notebook includes:
  - [ ] Title and your name
  - [ ] The first markdown cell contains the dataset name (required for the site)
  - [ ] Introduction/objective
  - [ ] Well-commented code
  - [ ] Visualizations with labels
  - [ ] Conclusions/insights
- [ ] No large data files (> 10MB) are included
- [ ] You haven't modified other students' work
- [ ] Your pull request has a clear title and description

## 📏 Code Standards

### Jupyter Notebook Structure

```python
# First Cell - Title (Markdown)
"""
# Project Title
**Author**: Your Name
**Date**: YYYY-MM-DD
**Course**: Course Name

Brief description of the project
"""
```

### Code Style
- Use meaningful variable names
- Add comments for complex logic
- Keep code cells focused and concise
- Use markdown cells to explain your analysis

### Visualizations
- Always include titles, axis labels, and legends
- Use appropriate chart types for your data
- Make visualizations readable (proper sizing, colors)

## 🚫 What Not to Do

- ❌ Don't modify files outside your personal folder
- ❌ Don't include sensitive or proprietary data
- ❌ Don't upload large datasets (use links instead)
- ❌ Don't submit incomplete or non-working notebooks
- ❌ Don't copy other students' work

## 📝 Pull Request Template

When creating a pull request, use this format:

```
**Student Name**: [Your Full Name]
**Course**: [Course Name]
**Project Title**: [Your Project Title]

**Description**:
Brief description of your project (2-3 sentences)

**Dataset**:
[Name and source of dataset used, if applicable]

**Key Technologies**:
- Python 3.x
- pandas
- matplotlib
- [other libraries]

**Checklist**:
- [x] All code runs without errors
- [x] Notebook is well-documented
- [x] Visualizations are clear and labeled
- [x] Conclusions are provided
```

## 🔄 Updating Your Submission

If you need to make changes after submitting:

1. Make changes in your forked repository
2. Commit the changes
3. Your pull request will automatically update

If your pull request has already been merged and you need to make changes:
1. Create a new pull request with the updates
2. Title it: "Update: [Original Project Name]"

## 💬 Communication

- Use pull request comments for project-specific questions
- Open an issue for general questions or problems
- Contact your instructor for course-related queries

## 🏅 Recognition

Once your pull request is merged:
- Your project becomes part of the public repository
- It serves as a portfolio piece
- It helps future students learn from your work

## 📧 Contact

For questions or assistance:
- Create an issue in this repository
- Contact your course instructor
